## Order of operations and shorthand

Order: parentheses, then `*` `/` `%`, then `+` `-`. Use parentheses to make your intention clear:

```js
(8 + 6 + 10) / 3   // the average: 8
```

The shorthand operators are the same as in C#:

- `counter++` / `counter--`: plus or minus 1
- `counter += 5` is `counter = counter + 5`, and the same for `-=`, `*=` and `/=`
