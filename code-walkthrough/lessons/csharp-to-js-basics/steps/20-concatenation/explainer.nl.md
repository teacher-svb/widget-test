## Strings aan elkaar plakken met +

`+` op strings plakt ze aan elkaar (**concatenatie**):

```js
"Ik ben " + firstName + " en ik ben " + age + " jaar."
```

**Let op:** is één operand een string, dan is het resultaat een string. `"1" + 2` is `"12"`, niet `3`. Dat gebeurt vaak met waarden uit een formulierveld.
