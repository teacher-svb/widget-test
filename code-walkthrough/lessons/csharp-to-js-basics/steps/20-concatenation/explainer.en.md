## Gluing strings with +

`+` on strings glues them together (**concatenation**):

```js
"Ik ben " + firstName + " en ik ben " + age + " jaar."
```

**Watch out:** if one operand is a string, the result is a string. `"1" + 2` is `"12"`, not `3`. This often happens with values that come from a form field.
