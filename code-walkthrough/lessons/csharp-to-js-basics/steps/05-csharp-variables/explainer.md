## Variabelen in C#

Een variabele is een plaats in het geheugen met een naam. Uit C# ken je dit al:

- eerst declareren, later toekennen: `int score;` en dan `score = 10;`
- een nieuwe waarde vervangt de oude: `score = 15;`
- een waarde kopiëren: `int highScore = score;`
- `const` voor een waarde die nooit verandert
