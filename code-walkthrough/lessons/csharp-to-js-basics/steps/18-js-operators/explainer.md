## Operatoren in JavaScript

- `+` `-` `*` `/`: zoals in de wiskunde
- `%` **rest**: `7 % 2` is `1`. Dit heeft niets met percentages te maken
- `**` **macht**: `2 ** 3` is `8`, in plaats van `Math.pow(2, 3)`

**Let op:** `7 / 2` is `3.5` in JavaScript. Er is maar één type number, dus er is geen gehele deling. Gebruik `Math.floor(7 / 2)` als je `3` nodig hebt.
