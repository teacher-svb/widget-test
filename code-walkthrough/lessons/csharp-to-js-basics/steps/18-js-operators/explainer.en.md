## Operators in JavaScript

- `+` `-` `*` `/`: as in maths
- `%` **remainder**: `7 % 2` is `1`. It has nothing to do with percentages
- `**` **power**: `2 ** 3` is `8`, instead of `Math.pow(2, 3)`

**Watch out:** `7 / 2` is `3.5` in JavaScript. There is only one number type, so there is no integer division. Use `Math.floor(7 / 2)` if you need `3`.
