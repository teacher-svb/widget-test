## Descriptive names in lowerCamelCase

```js
let totalPrice = price * quantity;
```

- **lowerCamelCase**: the first word in lowercase, every next word starts with a capital: `totalPrice`, `shoppingCart`, `myVeryLongName`
- In C# methods and properties use PascalCase (`GetTotal`). In JavaScript variables and functions use lowerCamelCase (`getTotal`)
- Fixed values: `UPPER_SNAKE_CASE`, such as `VAT_RATE`
- Be consistent: if you call something `user`, do not call the same thing `visitor` elsewhere
