## Strings en booleans

- Strings staan tussen dubbele aanhalingstekens, enkele aanhalingstekens of backticks. Dubbele en enkele werken hetzelfde: kies één stijl voor het hele project
- Backticks (template literals) berekenen wat tussen `${ }` staat, zoals `$"..."` in C#
- `toString()` zet elke waarde om naar tekst: `"3" + "3"` is `"33"`
- Een vergelijking zoals `price > 10` geeft een boolean. Vergelijkingen krijgen later een eigen hoofdstuk
