## Strings and booleans

- Strings go between double quotes, single quotes or backticks. Double and single quotes work the same: pick one style for the whole project
- Backticks (template literals) evaluate what is between `${ }`, like `$"..."` in C#
- `toString()` turns any value into text: `"3" + "3"` is `"33"`
- A comparison such as `price > 10` gives a boolean. Comparisons get their own chapter later
