## Types in JavaScript

- `int`, `double` → **number**: één type voor alle getallen
- `char`, `string` → **string**: er is geen type voor één teken
- `bool` → **boolean**: `true` of `false`
- `null` → **null**: bewust leeg
- **undefined**: nog geen waarde, bijvoorbeeld een gedeclareerde variabele die nooit een waarde kreeg (in C# compileert het lezen daarvan niet)
- **object** en **array**: complexe types, die komen in een later hoofdstuk

`typeof` toont het type van een waarde.
