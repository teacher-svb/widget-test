## Types in JavaScript

- `int`, `double` → **number**: one type for all numbers
- `char`, `string` → **string**: there is no type for one character
- `bool` → **boolean**: `true` or `false`
- `null` → **null**: deliberately empty
- **undefined**: no value yet, for example a declared variable that never got a value (in C# reading it does not compile)
- **object** and **array**: complex types, covered in a later chapter

`typeof` shows the type of a value.
