## let en const in JavaScript

- `int`, `string` en `var` worden allemaal `let`
- `const double VatRate` wordt `const VAT_RATE`: geen type, en vaste waarden schrijf je vaak in `UPPER_SNAKE_CASE`
- `Console.WriteLine` wordt `console.log`

Je declareert een variabele **één keer**. Een tweede `let score;` geeft een `SyntaxError`; na de declaratie gebruik je alleen nog de naam.

> JavaScript heeft ook `var`, de manier om variabelen te declareren van vóór 2015. Het werkt anders dan `let`, en ook anders dan `var` in C#. Gebruik het alleen in oude code.
