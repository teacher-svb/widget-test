## Commentaar in JavaScript

Precies hetzelfde als in C#: alleen `Console.WriteLine` is veranderd. Het commentaar is niet verschoven.

- `//` voor één regel, ook na code
- `/* ... */` voor meerdere regels, vaak gebruikt om code tijdelijk **uit te schakelen**

Sneltoetsen in VS Code:

- `Ctrl + /` zet `//` aan of uit op de geselecteerde regels
- `Shift + Alt + A` zet een `/* */`-blok aan of uit
