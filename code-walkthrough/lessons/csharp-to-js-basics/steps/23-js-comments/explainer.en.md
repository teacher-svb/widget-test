## Comments in JavaScript

Exactly the same as in C#: only `Console.WriteLine` changed. The comments did not move.

- `//` for one line, also after code
- `/* ... */` for several lines, often used to **switch code off** temporarily

Shortcuts in VS Code:

- `Ctrl + /` toggles `//` on the selected lines
- `Shift + Alt + A` toggles a `/* */` block
