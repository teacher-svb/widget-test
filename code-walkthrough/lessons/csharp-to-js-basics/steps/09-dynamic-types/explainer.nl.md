## Het type hoort bij de waarde

```js
userName = 42;   // mag in JavaScript
```

In C# compileert dit niet: `userName` is een `string`. C# is **strongly typed**, JavaScript is **dynamisch getypeerd**: een variabele bevat wat je erin stopt.

**Valkuil:** omdat het type kan veranderen, zie je niet altijd wat een variabele bevat. Geef een variabele één soort waarde en hou het daarbij.
