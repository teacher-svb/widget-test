## Referenties in C#

In C# beslist het **type** hoe een object doorgegeven wordt:

- een `class` is een referentietype: `World b = a;` maakt een tweede referentie naar **hetzelfde** object
- een `struct` is een waardetype: toewijzen maakt een kopie

Hier is `World` een class, dus `a.crateCount` is ook 5.
